# TreasureNova BEP20 Address Manager

On-device Android utility for accounts you own or are authorized to manage.

It logs in, opens Wallet/Deposit, selects USDT on BEP20 / BNB Smart Chain, copies the visible deposit address, logs out, then continues with the next account. Passwords stay in Android Keystore-backed storage and are never exported.

See BUILD.md for the exact compile commands.
